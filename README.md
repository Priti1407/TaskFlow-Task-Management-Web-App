# TaskFlow — Task Management Web App

A responsive task management project built with HTML, CSS, and vanilla JavaScript.

## Features
- Add, edit, complete, and delete tasks
- Save tasks in browser Local Storage
- Filter tasks by All, Today, Pending, and Completed
- Filter by Work, Personal, and Study categories
- Search tasks by title, description, category, or priority
- Sort by recently added, due date, priority, and title
- Task statistics and completion progress
- Responsive dark-lavender layout for desktop and mobile
- Form validation, confirmation before deleting, and status messages

## Run locally
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.
4. Tasks are stored in your browser using Local Storage.

## Project structure
- `index.html` — page structure
- `style.css` — theme, layout, responsive styles
- `script.js` — task CRUD, filters, sorting, search, and Local Storage
